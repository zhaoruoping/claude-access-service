SharedCC仅 Claude Code

在本机运行 Claude Code，账号与网络出口由服务器提供。

本机无需 Claude 账号，无需代理，无需配置环境变量。 Claude Code 在本机执行，读写本机文件；仅模型请求经服务器转发。

使用方式

环境要求

系统所需环境
WindowsWSL（Ubuntu 即可）
macOS自带终端
Linux直接可用

无其他要求。

安装

凭证包解压后，在其所在目录执行：

./install.sh

安装过程会检查本机的 Claude Code，未安装则自动安装，已安装则检查更新。 可重复执行。全程一至两分钟。

运行

sharedcc-claude

Claude Code 运行在本机，处理的是本机文件，本机的编辑器与终端照常使用。 参数原样转交，例如 sharedcc-claude -p "..."。

连接由工具自动建立与维护，中断后自动重连，无需手工操作。

常用命令

sharedcc-claude --quota     # 剩余额度与额度失效时刻
sharedcc-claude --status    # 连接状态
sharedcc-claude --update    # 更新到最新版本
sharedcc-claude --doctor    # 一键体检，生成诊断文件
sharedcc-claude --help      # 全部命令

出现问题时运行 --doctor，将生成的诊断文件发给管理员即可。 该文件只包含连接诊断信息，不含对话内容，不含任何密钥。

会话与数据

会话历史与本机自己的 claude 共用，--resume 与 --continue 在两边都能看到对方的会话。凭据与配置各自独立。

本工具的文件都在 ~/.sharedcc-claude/，不改动本机 ~/.claude 中的任何内容。

在服务器上运行

需要处理服务器上的文件时，sharedcc-claude --ssh 登录服务器上的独立环境。 该环境预装 Claude Code，为完整的 Linux 用户环境，可自行安装软件。

支付方式

免费测试

$5 额度 / 3 小时

每人一次，额度与时长以先到者为准。 测试期间数据保留，后续充值可直接继续使用，无需重装。

充值与额度

实付 1 ： 额度 20

额度以美元计价，按 Anthropic 官方 API 价格折算实际消耗。

最低 ¥50 起充。实付金额按 1:20 折算为额度， 再按固定汇率 ¥7 / $1 换算成美元结算。汇率固定而非浮动，账目任何时候都能复算。

例：实付 ¥50 → 额度 ¥1,000 → $142.86 可用额度。

额度如何计算

按实际消耗的 token 折算为美元，规则与官方定价一致：区分模型、区分输入输出， 缓存读写按官方倍率计。账目逐条可查，可随时索取本人的用量明细。

额度用尽仅停止发送新请求，不影响登录，不影响已有数据，充值后立即恢复。

额度周期

额度绑定周期，周期与账号的周额度刷新时刻同步。 额度在该时刻失效，未用完的部分不结转，继续使用需重新充值。

sharedcc-claude --quota 随时显示剩余额度与失效时刻。

车队与独享

车队：人数确定后可组固定车队，单价与上述一致， 额度与时长按车队整体安排。适用于同一课题组或同一项目共同使用。

独享：独立账号与独立环境，额度不与他人共享。 适用于用量较大或需要稳定预期的情况。按需报价。

优势

不是 API 中转

形式上有相似之处——都是把请求发到一个中间端点——但性质不同。

API 中转站SharedCC
上游按量计费的 API服务器上的 Claude Max 订阅账号
拿到手的一把 api key，可接任意客户端一套配好的环境，不发放任何 key
可用客户端任意仅 Claude Code
身份识别按 key按系统用户，key 无从冒用
可用性维护只提供一个地址网络出口、连接与断线重连均由服务端维护

「按官方 API 价折算」只是计价口径，用来把用量换算成可比较的金额， 并不表示上游走的是 API 计费。

代码不出本机

  • 文件始终在本机：Claude Code 在本机运行，读写的是本机文件，不会上传。
  • 本机不持有凭据：账号凭据仅存在于服务器，使用者侧不接触。
  • 不改动本机配置：工具的文件都在自己的目录内，本机原有的 claude 与 shell 配置不受影响。

可用性由服务端维护

  • 零配置：无需自备 Claude 账号，无需自备代理，无需配置环境变量。
  • 断线自愈：连接有常驻守护，休眠或切换网络后自动重连。
  • 出口固定：网络出口在服务器侧，长期运行验证过可用性。
  • 自更新：客户端启动时自动检查并更新。

隔离与记账

  • 独立环境：每人独立账号与独立家目录，相互不可见文件与进程。
  • 用量逐条记录：每次请求的模型与 token 消耗均有记录，账目可查、可核对。
  • 额度实时可见：--quota 显示剩余额度与失效时刻，每次请求后更新。

隔离与记账按实际结果验证，非仅配置声明。
