Claude 使用方案

一 · Claude 订阅协助无质保 注册与订阅开通全程协助，帮助优化降低封号概率的使用环境，账号交付后归本人所有。网页版、桌面端、Claude Code 均可使用。 二 · Claude Max 拼车共享提供质保 Claude Code 跑在本机，网络与请求经服务器转发，本机无需任何代理环境。多人共享一个账号，按实际用量计费。提供质保：账号被封或服务不可用，按剩余余额退款。仅支持 Claude Code。 三 · Claude 账号托管无质保 与拼车共享同一套使用方式，账号托管在服务器且个人独享，额度不与他人共享。本机同样无需代理环境。仅支持 Claude Code。

质保

三种服务中只有拼车共享提供质保，内容为两条：

  • 账号封禁风险由服务方承担：账号在服务方名下，风险不由使用者承担。
  • 不可用即退款：使用期内账号不可用的，按剩余余额退款。

订阅协助交付的账号归本人所有，账号托管为个人独享，两者均不含上述质保。 详见拼车共享 · 质保。
