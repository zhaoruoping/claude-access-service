Claude 使用方案

三种服务，独立并行，可相互切换。

一 · Claude 订阅协助 以本人身份与支付方式开通订阅，账号归本人所有。网页版、桌面端、Claude Code 均可使用。 二 · Claude Max 拼车共享 使用服务器上的账号与网络出口，多人共享，按实际用量计费。仅支持 Claude Code。 三 · Claude 账号托管 与拼车共享同一套使用方式，账号个人独享，额度不与他人共享。仅支持 Claude Code。
