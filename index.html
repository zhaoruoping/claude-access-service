Claude Code 共享环境

在自己的电脑上正常使用 Claude Code，不需要自备代理，也不需要自己的账号。

一句话：装一个安装包，之后照常敲 claude。代码和文件都在自己电脑上， 只有发给模型的那部分请求经由服务器转发。

解决的是什么问题

想用 Claude Code，通常要同时凑齐三样东西：一个可用的账号、一条稳定的网络出口、以及把两者接起来的配置。 任何一样出问题，命令行里看到的都只是一句连接失败。

这里把这三样都放在服务器上，使用者那边只需要一个 Linux 终端环境。

除此之外不需要别的：不需要自己的 Claude 账号，不需要自己的代理，不需要配置任何环境变量。

怎么运行的

安装包会在本机装两样东西：一条到服务器的加密隧道，和一个启动器。

你的电脑                        服务器
────────                       ────────
claude（本机运行，读写本机文件）
   └─ 模型请求 ──加密隧道──▶ 账号与网络出口 ──▶ 官方 API
  • 代码不出本机：Claude Code 跑在你自己电脑上，读写的是你自己的文件。
  • 本机不持有任何凭据：账号凭据只存在于服务器上，使用者拿不到、也不需要拿到。
  • 断线自愈：隧道有常驻守护，休眠、换网络之后会自动接回。

另外两种用法

除了在本机跑，也可以直接登录服务器上的独立环境干活，或者在本机与服务器之间同步文件。 安装包里都带好了，用不上可以忽略。

环境与隔离

  • 每人一套独立环境：独立账号、独立家目录，互相看不到对方的文件和进程。
  • 凭据不落到使用者手里：请求在服务器侧补齐认证，使用者侧接触不到凭据本身。
  • 用量逐条记账：每一次请求的模型与 token 消耗都有记录，账目可查、可对。
  • 网络出口经过实测：出口节点是长期跑下来验证过可用的，不是随手挑的。

隔离与记账都是按结果验证过的，不是"配置上应该如此"。

独享

独立账号与独立环境，不与他人共享额度。适合用量大或需要稳定预期的情况。按需报价。

额度怎么算

按实际消耗的 token 折算成美元，规则与官方定价一致：区分模型、区分输入输出、缓存读写按官方倍率计。 账目逐条可查，随时可以要一份自己的用量明细。

额度用尽只会停止发送新请求，不影响登录，也不影响已有数据，充值后立即恢复。

常见问题

需要我自己有 Claude 账号吗

不需要。

需要我自己有代理吗

不需要。网络出口在服务器侧，本机不需要任何代理配置。

我的代码会被看到吗

在本机运行时，代码和文件始终在你自己的电脑上，不会上传。 如果选择登录服务器干活，那部分文件在你自己的独立家目录里，其他使用者看不到。

Windows 能用吗

能，装 WSL 即可，安装包在 WSL 里运行。

额度用完了会怎样

只会停止发送新请求。登录、文件、环境都不受影响，充值后立刻恢复，不需要重装。

时长到期了会怎样

暂停登录，但账号、家目录和数据全部保留，续费即可继续，不需要重新安装或重新配置。

能自己装东西吗

可以，环境是完整的 Linux 用户环境。

怎么开始

拿到安装包之后解压，运行 ./install.sh，之后照提示敲一条命令即可。整个过程一两分钟。
