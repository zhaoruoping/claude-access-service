Claude 使用方案

两种方式，独立并行。

方式一 · 共享环境：使用服务器上的账号与网络出口， 无需自备账号与代理。仅支持 Claude Code（命令行）。

方式二 · 协助订阅：以本人身份与支付方式开通订阅， 账号归本人所有。网页版、桌面端、Claude Code 均可使用。

方式一 · 共享环境仅 Claude Code

这不是 API 中转

形式上有相似之处——都是把请求发到一个中间端点——但性质不同。

API 中转站本方式
上游按量计费的 API服务器上的 Claude Max 订阅账号
拿到手的一把 api key，可接任意客户端一套配好的环境，不发放任何 key
可用客户端任意仅 Claude Code
身份识别按 key按系统用户，key 无从冒用
可用性维护只提供一个地址隧道、网络出口、断线重连均由服务端维护

「按官方 API 价折算」只是计价口径，用来把用量换算成可比较的金额， 并不表示上游走的是 API 计费。

适用范围

本方式提供的是 Claude Code 命令行的使用能力， 不包含网页版 claude.ai 与桌面端。需要网页版或桌面端的，见方式二。

账号与网络出口均在服务器侧，使用者无需自备 Claude 账号，也无需自备代理。

环境要求

系统所需环境
WindowsWSL（Ubuntu 即可）
macOS自带终端
Linux直接可用

无其他要求：不需要 Claude 账号，不需要代理，不需要配置环境变量。

运行方式

凭证包在本机装入一条到服务器的加密隧道和一个启动器。安装后运行 sharedcc-claude，Claude Code 在本机执行，读写本机文件；仅模型请求经隧道由服务器转发。

本机                                      服务器
────────                                 ────────
sharedcc-claude（本机运行，读写本机文件）
   └─ 模型请求 ──加密隧道──▶ 账号与网络出口 ──▶ 官方 API
  • 代码不出本机：Claude Code 在本机运行，读写的是本机文件。
  • 本机不持有凭据：账号凭据仅存在于服务器，使用者侧不接触。
  • 断线自愈：隧道有常驻守护，休眠或切换网络后自动重连。

附带功能

sharedcc-claude --ssh 可登录服务器上的独立环境作业。该环境预装 Claude Code， 为完整的 Linux 用户环境。按需使用。

隔离与记账

  • 不保存对话内容：Claude Code 运行在本机，服务器只做两件事——转发模型请求、 记录 token 用量。账目的字段是固定白名单（时间、用户、模型、状态、token 数）， 请求与回复的正文不写入任何日志。
  • 凭据不外发：认证在服务器侧补齐，使用者侧接触不到凭据本身。
  • 用量逐条记录：每次请求的模型与 token 消耗均有记录，账目可查、可核对。
  • 互不可见：登录服务器作业时，每人独立账号与独立家目录， 相互看不到文件与进程。
  • 出口节点经实测：长期运行验证过可用性。

隔离与记账按实际结果验证，非仅配置声明。

四档，可相互切换，无需重装。

免费测试

每人一次。额度与时长两项独立计算，任一用尽即停止对应部分： 额度用尽停止发送新请求，时长到期暂停登录。 充值后可直接继续使用，无需重装。

临时拼车 · 按周订阅

实付 1 ： 额度 20

额度以美元计价，按 Anthropic 官方 API 价格折算实际消耗。 同等用量下，成本约为直接调用官方 API 的二十分之一。

最低 ¥50 起充。实付金额按 1:20 折算为额度， 按 固定汇率 ¥7 / $1 换算成美元结算（固定而非浮动，账目任何时候都能复算）。 例：实付 ¥50 → 额度 ¥1,000 → $142.86 可用额度。

额度绑定周期，周期与账号的周额度刷新时刻同步。额度在该时刻失效，未用完的部分不结转， 继续使用需重新充值。

车队

人数确定后可组固定车队，单价与临时拼车一致，额度与时长按车队整体安排。 适用于同一课题组或同一项目共同使用。

独享

独立账号与独立环境，额度不与他人共享。适用于用量较大或需要稳定预期的情况。按需报价。

额度计算

按实际消耗的 token 折算为美元，规则与官方定价一致：区分模型、区分输入输出，缓存读写按官方倍率计。 账目逐条可查，可随时索取本人的用量明细。

额度用尽仅停止发送新请求，不影响登录，本机文件不受影响，充值后立即恢复。

常见问题

这和 API 中转站是一回事吗

不是。中转站转售的是按量计费的 API 额度并发放 api key；本方式的上游是服务器上的 Claude Max 订阅账号，提供的是一套配好的 Claude Code 环境，不发放任何 key。 计费时按官方 API 价折算，那只是把用量换算成可比较金额的口径。详见方式一首节。

是否需要自备 Claude 账号

方式一不需要。方式二需要，开通后账号归本人所有。

是否需要自备代理

方式一不需要，网络出口在服务器侧。方式二需要自备，或采用推荐方案。

能否使用网页版 claude.ai

方式一不可以，仅提供 Claude Code 命令行。需要网页版或桌面端请选择方式二。

代码是否会被上传

不会。方式一的 Claude Code 运行在本机，代码与文件始终在本机。 服务器只转发模型请求并记录 token 用量，对话内容不写入任何日志。 若选择登录服务器作业，该部分文件位于本人的独立家目录，其他使用者不可见。

Windows 是否可用

可用。安装 WSL 后在 WSL 中运行安装包。

额度用尽后如何处理

仅停止发送新请求。登录与本机文件不受影响，充值后立即恢复，无需重装。

时长到期后如何处理

暂停登录。续费后继续使用，无需重新安装或配置。

能否自行安装软件

可以，环境为完整的 Linux 用户环境。

如何开始

方式一：解压凭证包后运行 ./install.sh，随后运行 sharedcc-claude， 全程一至两分钟。详见 SharedCC 说明页。
方式二：联系说明所需档位。
