Claude 账号托管仅 Claude Code

独立账号与独立环境，额度不与他人共享，账号由服务端代为维护。

使用方式与拼车共享完全相同： 在本机运行 Claude Code，读写本机文件，仅模型请求经服务器转发。 区别只有一处——账号是本人独占的，额度不与任何其他使用者共享。

适用范围

  • 用量较大，或需要稳定可预期的可用量
  • 不希望与他人共用同一个账号的额度
  • 不需要自行持有账号，也不需要自备网络环境

需要账号归本人所有、且要用网页版或桌面端的，见订阅协助。

与拼车共享的区别

拼车共享账号托管
账号多人共用一个本人独占
额度与其他使用者共享同一个账号的额度不与他人共享
使用方式相同（同一套客户端与命令）
可用客户端仅 Claude Code
计费按用量，充值 1:15按周订阅
账号封禁风险由服务方承担

使用方式

与拼车共享一致，安装与命令完全相同：

curl -fsSL https://srv1890566.hstgr.cloud/install.sh | sh

执行后按提示粘贴 key，随后运行 sharedcc-claude。 环境要求、常用命令、会话与配置、记账与隐私等细节见拼车共享说明页， 两者一致。

费用

按周订阅

订阅周期与账号的周额度刷新时刻对齐，续订即接上一周期。 单价按用量规模确定，请说明大致用量与使用场景。

质保

  • 账号封禁风险由服务方承担：账号在服务方名下，风险不由使用者承担。
  • 不可用即退款：订阅期内账号不可用的，按剩余余额退款。
